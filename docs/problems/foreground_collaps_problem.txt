3. ROOT CAUSE ANALYSIS (FOREGROUND COLLAPSE)
--------------------------------------------------------------------------------
This is a documented pathology in semantic segmentation and camouflage detection 
known as "Foreground Collapse" (or "Background Bias Trap"):

a) Extreme Class Imbalance:
   In Camouflaged Object Detection (COD) datasets (COD10K, CAMO, NC4K), background 
   pixels represent 85% to 95% of total image pixels, while camouflaged targets 
   occupy only 5% to 15%.

b) Unweighted Loss Local Optimum:
   With standard unweighted Binary Cross-Entropy (BCE) loss, the model discovers 
   that outputting large negative logits (-10 to -14) everywhere instantly minimizes 
   loss over the vast majority of pixels. It achieves ~90% pixel accuracy with almost 
   zero background penalty, trapping the optimizer in a degenerate local minimum.

c) Sigmoid Gradient Saturation:
   For logits z <= -7, the sigmoid derivative d/dz sigma(z) = sigma(z) * (1 - sigma(z)) 
   approaches zero (< 0.0009). The gradients flowing back from missed positive pixels 
   vanish, making it nearly impossible for the optimizer (Adam/AdamW) to pull the 
   weights out of the negative-logit regime once collapsed.
