1. PROBLEM SUMMARY
--------------------------------------------------------------------------------
The model was previously collapsing to a degenerate state where it predicted 
large negative logits (-11 to -14) everywhere, producing all-black masks (zero 
detected pixels) across all test samples. This occurred because:
  a) Severe class imbalance in COD (85-95% background).
  b) Standard unweighted Binary Cross-Entropy (BCE) allowed the network to 
     minimize total loss fastest by predicting 100% background.
  c) Learning rate was too high (0.001 vs official 0.0001), causing gradient 
     explosions early in training and locking weights into negative saturation.


2. THE OFFICIAL DGNet MECHANISM & SOLUTION
--------------------------------------------------------------------------------
In the official DGNet paper and repository (GewelsJI/DGNet), the authors 
prevented this failure mode using a dedicated multi-task loss formulation:

  Total_Loss = Structure_Loss(mask_pred, mask_gt) + lambda_grad * MSE(grad_pred, grad_gt)

Where Structure_Loss consists of two key components:

A. Adaptive Boundary & Foreground Weight Map (`weit`):
   Instead of treating all pixels equally, DGNet computes a pixel-wise adaptive 
   weight map using an average pooling window of 31x31 subtracted from the GT mask:
   
       weit = 1.0 + 5.0 * |AvgPool2D(mask, 31x31) - mask|
   
   - Solid background far from objects: weit = 1.0
   - Hard object boundaries & camouflaged bodies: weit = 6.0 (6x penalty)
   
   If the network attempts to predict all-black to minimize background loss, 
   the 6x penalty on missed target pixels drives the loss extremely high, 
   completely preventing the network from settling into the black-mask local minimum.

B. Weighted Binary Cross-Entropy (`wbce`):
   Calculates cross-entropy weighted by the spatial importance map `weit`:
   
       wbce = sum(weit * BCE_pixelwise) / sum(weit)

C. Weighted IoU Loss (`wiou`):
   A regional intersection-over-union loss weighted by `weit`:
   
       inter = sum((pred_sigmoid * mask) * weit)
       union = sum((pred_sigmoid + mask) * weit)
       wiou  = 1.0 - (inter + 1.0) / (union - inter + 1.0)

   If the model predicts all zeros (pred = 0), wiou evaluates to its absolute 
   maximum penalty (1.0), enforcing a continuous gradient signal toward positive detection.

D. Auxiliary Gradient Loss (MSE):
   Computes Mean Squared Error against the ground truth Sobel edge map:
   
       grad_loss = MSE(grad_pred_sigmoid, grad_gt)
   
   This forces the shallow texture encoder branch to learn sharp high-frequency 
   boundary features rather than collapsing.


3. IMPLEMENTATION DETAILS APPLIED TO CODEBASE
--------------------------------------------------------------------------------
The official DGNet mechanism has been ported into TensorFlow 2.x across the project:

1. `src/models/dgnet.py`:
   - Updated `DGNetLoss` to implement the exact `structure_loss` formula:
     * `avg_pool = tf.nn.avg_pool2d(y_true, ksize=[1, 31, 31, 1], strides=[1, 1, 1, 1], padding="SAME")`
     * `weit = 1.0 + 5.0 * tf.abs(avg_pool - y_true)`
     * `wbce = sum(weit * bce_raw) / sum(weit)`
     * `wiou = 1.0 - (inter + 1.0) / (union - inter + 1.0)`
     * Auxiliary gradient loss switched from MAE to `MSE(gt_grad, grad_pred_sig)`.

2. `params.yaml`:
   - Aligned training hyperparameters to official DGNet:
     * `learning_rate`: Reduced from `0.001` to `0.0001` (1e-4) to prevent gradient instability.
     * `lambda_grad_loss`: Set to `1.0` (matching official DGNet weighting).

3. `scripts/DGnet.py`:
   - Gradient clipping margin set to `clipnorm = 0.5` (matching official DGNet `clip = 0.5`).
   - Default learning rate set to `0.0001`.
   - Linear warmup (first 5 epochs) + cosine decay scheduler configured.


4. VERIFICATION & NEXT STEPS
--------------------------------------------------------------------------------
With `structure_loss` and calibrated hyperparameters active:
1. Retrain the model:
       python scripts/DGnet.py --train --epochs 50 --batch-size 8

2. The model will no longer be able to cheat by outputting pure negative logits, 
   as the 6x weighted structure loss penalizes false negatives severely.
